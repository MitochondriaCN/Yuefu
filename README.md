## 简介

**乐府**是一款为音乐学习者量身打造的AI应用。

乐府主要具有以下功能：

- 通过拍照或图片，智能识别五线谱，包括音高、拍号、速度、调号等元素
- 根据所识别的乐谱，生成可视化钢琴键盘瀑布流
- 对乐谱进行结构化解析，如解析主旋律、伴奏等

## 框架与依赖

- Jetpack Compose
- Room
- MidiDriver
- Dom4j
- Retrofit
- Hilt

## 自白

该项目主要是为了软创比赛而开发。虽然把五线谱转换成音频的想法可能很有意思，也很实用，但是坦诚地说，我们的模型和软件还没有办法完美地实现这项功能。软创这种比赛并不是一个完全的技术竞赛，而是比较依赖包装和叙事，在某种程度上是一种PPT竞赛，因此最后取得全国二等奖，也无可厚非。

虽然比赛含金量有限，但是我个人觉得，想法还是很有价值的。我们从始至终，都是将其作为一个面向普通用户、面向真实使用场景的产品来打造，而不是那种PPT上好看、实际拿不出手的项目。以我们目前的技术水平，做到了初步可用，拍一份乐谱，大概能识别出90%的音符。不过要想追求超高准确率，以及真正做到可以被用户依赖，那还有很远的距离。如果在下未来有机会，或许可以进行这方面的研究，毕竟确实是非常有趣的一个想法。如果真的能做到好用，那么无论在音乐界还是技术界，都会是一个重磅成果。

现在将代码开源，可以为开源世界增加一些反面或正面的教材。
