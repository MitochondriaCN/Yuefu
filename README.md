# 乐府

第十九届全国大学生软件创新大赛全国赛二等奖作品

@Flutter-Misdreavus, @bingxunqing, @QiChenSn, @MitochondriaCN

## 简介

**乐府**是一款为音乐学习者量身打造的AI应用。

乐府主要具有以下功能：

- 通过拍照或图片，智能识别五线谱，包括音高、拍号、速度、调号等元素
- 根据所识别的乐谱，生成可视化钢琴键盘瀑布流
- 对乐谱进行结构化解析，如解析主旋律、伴奏等

## 框架与依赖

- Jetpack Compose
- Room
- MidiDriver
- Dom4j
- Retrofit
- Hilt

## 自白

该项目主要是为了软创比赛而开发。虽然把五线谱转换成音频的想法可能很有意思，也很实用，但是坦诚地说，我们的模型和软件还没有办法完美地实现这项功能。软创这种比赛并不是一个完全的技术竞赛，而是比较依赖包装和叙事，在某种程度上是一种PPT竞赛，因此最后取得全国二等奖，也无可厚非。

虽然比赛含金量有限，但是我个人觉得，想法还是很有价值的。以我们目前的技术水平，还没有办法完美实现这项功能。如果未来有机会，或许可以进行这方面的研究。现在将代码开源，可以为开源世界增加一些反面或正面的教材。

最为感谢的是我的三位队友。我们在一起度过了大概半年的时光，写代码、修改PPT、练习答辩，去东莞比赛。他们把我一个法学生带进了计算机类的全国级竞赛，为我未来的升学积累了一张好牌。这将是我大学生活中最有回忆价值的经历之一。
